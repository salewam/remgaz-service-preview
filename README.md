# РемГазСервис — Полная документация проекта и автоматизации

## 1. Структура проекта

- **index.html**, **gas.html**, **portfolio.html** — основные публичные страницы сайта.
- **admin/** (`admin/index.html`) — панель управления и Mini App для Telegram.
- **assets/**:
  - `form.js` — валидация форм, отправка заявок, полноэкранное модальное окно успешной отправки с кнопкой «Окей».
  - `case-carousel.js` — автоматическое плавное перелистывание карточек объектов портфолио раз в 7 секунд (без лишних кнопок).
  - `site-content.js` — динамическая подгрузка актуальных проектов и цены с бэкенда (`/api/content`).
  - `admin.js`, `admin.css` — логика интерфейса управления контентом и просмотра заявок.
  - `phone.js` — перехват кликов по телефону с диалогом звонка/копирования.
  - `fonts/`, `images/`, `projects/` — шрифты, графика и фотографии выполненных объектов.
- **content/** (`site.json`) — исходный снимок контента сайта (проекты, описания, характеристики, фото).
- **server/**:
  - `http.mjs` — основной HTTP-сервер Node.js (раздача статики, API заявок, API контента, админка).
  - `lead.mjs` — сервис обработки, валидации, защиты от спама и мульти-рассылки заявок в Telegram.
  - `content.mjs` — сервис хранения и обновления контента (SQLite, версионирование, загрузка фото).
  - `telegram-admin.mjs` — проверка HMAC-SHA256 подписи Telegram Web App `initData`.
  - `config.mjs` — загрузка и строгая валидация переменных окружения.
- **deploy/**:
  - `install-assets.mjs` — атомарная установка версионированных статических ресурсов.
  - `nginx.mjs` / `server.env.example` — шаблоны конфигурации веб-сервера и переменных окружения.
- **scripts/**:
  - `build.mjs` — скрипт сборки продакшн-дистрибутива с хешированием ресурсов.

## 2. Автоматизация прихода заявок

### Принцип работы
1. Пользователь заполняет форму на сайте (`index.html` или `gas.html`) в любом порядке (фокус свободен).
2. При отправке форма шлёт POST-запрос на `/api/lead` с `Idempotency-Key`.
3. Бэкенд атомарно сохраняет заявку в базу SQLite (`leads.sqlite`, таблица `leads`) со статусом `queued`.
4. Сразу после сохранения бэкенд инициирует отправку уведомления в Telegram через Bot API (`sendMessage`).
5. **Мульти-рассылка всем операторам:**
   - Таблица `lead_recipients` хранит список всех авторизованных чатов.
   - Каждый человек, открывший Telegram Mini App («Управление сайтом» в `@remgaz_aibot`), автоматически добавляется в `lead_recipients`.
   - Заявка отправляется **каждому** подключённому оператору независимо.
   - Если один оператор заблокировал бота, остальные всё равно гарантированно получают уведомление.
   - Если заявка пришла, когда операторов ещё не было, она сохраняется в очереди (`queued`) и моментально доставляется новому оператору при его первом входе.
6. На сайте после подтверждения сервером моментально всплывает полноэкранное окно:
   - Заголовок: **«Ваша заявка отправлена»**
   - Текст: **«Мы свяжемся с вами в ближайшее время.»**
   - Кнопка: **«Окей»** (закрывает окно и возвращает страницу в нормальное состояние).

## 3. Автоматизация дополнения портфолио

### Принцип работы
1. Оператор открывает бота `@remgaz_aibot` и нажимает кнопку меню **«Управление сайтом»**.
2. Открывается Mini App (`/admin/`):
   - Доступ защищён криптографической проверкой Telegram `initData` по токену бота.
   - Во вкладке **«Портфолио»** можно редактировать существующие объекты или нажать **«+ Новый объект»**.
   - Доступны поля: название, категория, подзаголовок, краткое описание для карточки, полное описание, выполненные задачи, характеристики (объём резервуара, мощность котлов, сроки), загрузка фотографий.
3. При сохранении:
   - Данные записываются в `content.sqlite` с инкрементом номера ревизии (`revision`).
   - Новые фотографии сохраняются в медиа-хранилище.
4. На главной странице сайта:
   - Скрипт `assets/site-content.js` опрашивает `/api/content`.
   - Новые опубликованные объекты автоматически встраиваются в ленту портфолио.
   - Карусель (`assets/case-carousel.js`) автоматически подхватывает новые карточки и включает их в бесконечный цикл плавного перелистывания раз в 7 секунд.

## 4. Развёртывание и запуск

1. **Требования:**
   - Node.js >= 22 (рекомендуется v24 с встроенной поддержкой `node:sqlite`).
   - Обратный прокси-сервер (Caddy или Nginx) с поддержкой SSL/HTTPS.

2. **Переменные окружения (`server.env`):**
   ```env
   PUBLIC_ORIGIN=https://ваш-домен.ru
   LEAD_ALLOWED_ORIGINS=https://дополнительный-домен.ru
   TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
   TELEGRAM_CHAT_ID=
   LEAD_IP_HASH_SECRET=случайный_секрет_длиной_не_менее_32_байт
   LEAD_DB_PATH=/var/lib/remgaz/leads.sqlite
   CONTENT_DB_PATH=/var/lib/remgaz/content.sqlite
   CONTENT_MEDIA_DIR=/var/lib/remgaz/media
   HOST=127.0.0.1
   PORT=18082
   ```

3. **Сборка и запуск:**
   ```bash
   npm install
   npm run build
   node server/http.mjs
   ```

4. **Запуск через systemd:**
   Создайте службу `/etc/systemd/system/remgaz.service`:
   ```ini
   [Unit]
   Description=Remgaz website API and Telegram administration
   After=network.target

   [Service]
   Type=simple
   User=root
   WorkingDirectory=/opt/remgaz/current
   EnvironmentFile=/etc/remgaz/server.env
   ExecStart=/usr/bin/node server/http.mjs
   Restart=on-failure
   RestartSec=5

   [Install]
   WantedBy=multi-user.target
   ```
